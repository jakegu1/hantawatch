# 核心行为（每次动手前读）

> 项目无关，直接复用、不改。复制到每个项目的 rules/00-core.md。

1. **先想后写**：动手前列出假设；有多种合理解读就停下问，别猜了硬上。
2. **简单优先**：只写满足当前任务的最小代码；不做没人要的抽象 / "灵活性" / 额外功能。
3. **外科手术式改动**：只碰当前任务直接需要的代码；不顺手重命名/重排/重格式化无关部分；
   每行改动都能追溯到任务。
4. **目标驱动**：先把模糊指令翻成可验证的成功标准，再写/观察一个检查让它通过；
   以类型检查/构建/测试为正确性信号。
5. **主动提更优解**：看到更好/更持久的做法或架构风险，立刻直说，别闷头干；
   优先有长期价值的方案而非权宜之计。
