# 病毒观察 / hantawatch — PRD（v1）

> 本文件冻结"做什么 + 不做什么"。新需求一律进 @docs/backlog.md，不在本版加。
> 任务顺序见 @docs/PLAN.md。完成判定与角色见 @rules/10-project.md。

## 1. 谁 & 为什么
- **目标用户**：在小红书/微信刷到传染病传言（当前主要是汉坦病毒）、心里发慌的普通中文用户，移动端为主。
- **真实痛点**：社交平台上疫情传言放大恐慌，但散落、无来源、无法判断"离我远不远、要不要慌"。用户要的不是论文，是**一句可信、带证据、能立刻安心的判断**。
- **背景**：工具诞生于汉坦爆发期，截图发小红书后爆火（数万流量、数千评论、500+ 粉丝）。当前汉坦区域平静，价值模型从"告诉我有多严重"转为"告诉我没事、并给我证据"。

## 2. 这一注怎么下（核心假设：为什么这么做有效）
- **reassurance-first**：平静期的核心价值是"安心",不是"告警"。先给一句带 `source`+`asOf` 的判断("离我远/近、要不要慌"),再让想深究的人一跳看到可溯源数字。
- **增长靠自发分享**：已被验证的获客引擎是"一屏截图就能转发"。所以**把可截图转发的可溯源安心判断打磨到极致**,而不是追留存功能（个人主体也做不了）。
- **信任来自克制**：绝不自称官方、绝不假数据、绝不虚假精度。暂无数据胜过假数据——这正是它区别于传言的护城河。

## 3. 核心循环 / 主流程（产品 IS 这个流程）
1. 用户带着"看到传言、有点慌"的状态打开（小程序或网页）。
2. 首页 5 秒内给出 reassurance-first 判断（带 source + asOf）。
   **2026-08-28 起首屏是「传言体温计」**：按病种给出"WHO 最近一次通报是什么时候"，
   汉坦从"整个产品"降为"本站深度追踪的那一个事件"。
3. 想深究 → 一跳看到支撑判断的可溯源数字（确诊/死亡/疑似/输入，每个带来源链接 + 截至日期）。
4. 这一屏可直接截图转发 → 朋友看到 → 回到第 1 步（自发获客闭环）。

## 4. 这版"完成"=（唯一判据，一句话）
> 一个在小红书/微信刷到汉坦传言、心里发慌的中文用户，打开病毒观察（小程序或网页），**5 秒内**读到一句带 `source`+`asOf` 的「离我远不远、要不要慌」判断；想深究时能一跳看到支撑该判断的**可溯源数字**——全程**无需注册、不留任何信息**，且**这一屏截下来就能直接转发**。

## 5. OUT OF SCOPE（binding！不做、也不"为它做准备"）← 防 creep 命根子
1. **小程序端任何留资**：反馈表/账号/订阅/登录/推送——个人主体会被审核驳回。升级个体工商户/公司后再议。
2. **微信支付 / 视频号 / 服务端 PII 存储 / 个性化推送**——合规红线，本版硬边界。
3. **网页端留资**（邮件订阅/账号）——本版也不做。理由非审核，而是 PIPL 后端合规负担 + 目前无"值得回访推送的内容",留资是空转。全端保持零 PII。
4. ~~**扩疾病 / 扩血清型**~~ → **2026-08-28 Jake 批准移入 V2 范围（见 @docs/strategy-post-hanta.md）**，但带死约束：
   - 只做**事件级**：每个病种只回答"WHO 最近一次为它发疫情通报是什么时候 + 原文链接"。
   - **绝不为第二个病种建病例账本**（逐国确诊/疑似核对只属于当前主线疫情）。这是数据债的分界线。
   - 病种是**有限清单**，不是"所有传染病"：汉坦 + 流感 + 登革热 + 诺如 + 埃博拉 + Mpox。加病种要单独过闸门。
   - 「WHO 没有条目」必须显示为**一等答案**，且必须同时说明"不等于没有病例"。
   - 实现见 `services/collector/hantawatch_collector/disease_watch.py` 与 `packages/shared/src/disease-watch.ts`。
5. **城市级个性化数据**（R2 选城市/分省精度）——前提是真实分城市数据,没有就不做（暂无数据胜过假数据）。
   **仍然关闭**：T0 spike 已证明公开可引用的最细粒度是省级，区县/城市级发病率不存在可引用版本。
   国家级（出国目的地）不受此条限制——那是原生国家粒度，见 V2 的 L3。
> 冻结需求面：以上任一冒头，写进 @docs/backlog.md，不在本版加；越界先出声。

## 6. 非功能要求
- **可溯源**：每个对外展示的事实型数字必须带 `source`(URL)+`asOf`(日期)，并被 `guard` 阻断无来源数字。
- **不虚假精度**：距离四舍五入到 100km；指数不臆造小数位；距离为 0 视为未地理编码、排最后，不报"0km 告警"。
- **合规**：小程序类目永远工具/资讯/科普，永不医疗/健康；文案绝不自称官方/疾控/权威。
- **性能/体验**：移动优先；首页判断 5 秒内可读；`DataFreshness` 相对时间在 mount 后算（避免 React #425 hydration）。
- **单一数据源**：web 与小程序共用 `apps/web/src/data/*.json`，绝不维护第二份。
